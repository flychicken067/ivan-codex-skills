# Ivan Skill Pack

Plugin bundle for Codex that includes:

- `ivan-human-ui`
- `ivan-bazi-architect`
- `ivan-youmind-skill-cover`
- `ivan-sun-study-reversal`

## Included Skills

### `ivan-human-ui`

Use for UI polish, anti-template cleanup, visual hierarchy refinement, and media visibility verification.

### `ivan-bazi-architect`

Use for explicit BaZi or 命理 requests that need indexed local references, citations, and structured output.

### `ivan-youmind-skill-cover`

Use to turn an abstract Skill into a YouMind-ready cover with a recognizable user, real input, and concrete output.

### `ivan-sun-study-reversal`

Use to deconstruct numbers, objects, and narrative pricing power, then write a clearly fictionalized female-first-person reversal.

## Layout

- `.codex-plugin/plugin.json`: plugin manifest
- `skills/ivan-human-ui`: UI skill
- `skills/ivan-bazi-architect`: BaZi skill
- `skills/ivan-youmind-skill-cover`: YouMind value-cover skill
- `skills/ivan-sun-study-reversal`: narrative reversal skill
