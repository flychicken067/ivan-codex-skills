# 瑞德三个 Skill 的封面叙事参考

这些是参考，不是固定文案。只在用户要制作瑞德工作台 Skill 封面时使用。

## 产品资料问答

- 人物：直播间主播、客服或销售
- 输入：顾客临时询问产品规格，人物在散乱文档里查找
- 输出：一句能直接回答顾客的结论、适用条件、风险提醒和可定位来源
- 核心变化：从“不敢答、找不到”到“有依据地立即回答”

## 竞对信息抓取

- 人物：产品专员或业务负责人
- 输入：多个网页、价格、规格、截图散落，无法比较
- 输出：证据截图、来源网址、更新时间和统一字段的竞品对比
- 核心变化：从“凭印象讨论”到“拿证据做决定”

## 产品展示页生成

- 人物：产品负责人、设计或研发
- 输入：产品文档、图片、合规字段和零散需求
- 输出：可预览、可批注、等待人工确认的产品展示页草稿
- 核心变化：从“反复转述需求”到“围绕真实页面确认”
